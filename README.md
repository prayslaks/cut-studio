# TTS Studio

영상에 나레이션(ElevenLabs TTS)·자막·인트로/챕터/엔딩 카드·썸네일·유튜브 업로드 문구를 붙여 MP4로 내보내는 로컬 웹앱.
**프로젝트** 단위로 작업하며, 어떤 영상이든 추가해서 쓸 수 있습니다. (ProjectZK 홍보 영상 작업에서 시작)

## 실행
- `start.bat` 더블클릭 (Node.js 18+ 필요) → 브라우저가 http://localhost:5178 으로 열림
- 또는 `node server.mjs`
- ffmpeg 필요: `winget install Gyan.FFmpeg` (libass 포함 빌드)

## 프로젝트
- 처음 실행하면 **프로젝트 시작 화면**: 최근 프로젝트 / 새 프로젝트 / 폴더에서 열기
- 프로젝트 = 폴더 하나 (`script.json` + `tts/` + `thumbs/` + `fonts/`). 기본 위치 `내 비디오\TTS Studio\<이름>`, 만들 때 변경 가능
- 새 프로젝트 설정 (상단 `프로젝트 설정`에서 언제든 수정)
  - **브랜드 문구** `{brand}` · **대표 키워드** `{tagline}` · **부제 형식** `{subtitle}` (`{title}` = 영상 제목): 인트로·엔딩 카드와 썸네일 템플릿의 기본 문구
  - **프로젝트 설명**: AI 어시스턴트·썸네일 초안·업로드 문구 추천이 사실·톤의 근거로 사용
  - **출력 폴더**: MP4·SRT·썸네일 PNG 저장 위치 (기본 `프로젝트\output`)
- 상단 프로젝트 이름(▾)을 눌러 다른 프로젝트로 전환
- **영상 추가** (`＋ 영상` 탭): PC 폴더를 탐색해 영상 파일 선택(복사하지 않고 원래 위치 사용) → 제목·날짜·엔딩 문구, **사용할 구간**(앞뒤 자르기·중간 빼기: 원본을 보면서 `⇤`/`⇥`로 현재 위치를 구간 시작/끝으로), 구간별 **챕터 제목**(적은 구간만 챕터 카드 표시), 엔딩 카드 길이
- 영상 탭의 ⚙(또는 더블클릭)으로 같은 설정을 다시 열기·영상 빼기
- 이전 버전(작업 폴더 하나만 쓰던 방식)의 `studio.config.json`이 있으면 첫 실행 때 그 폴더를 프로젝트로 자동 등록(원본 `script.preupgrade.json` 백업)

## 설정
상단 `⚙ 설정`: API 키(ElevenLabs / Claude / OpenAI, 연결 테스트), AI 제공자·모델, ffmpeg 경로, 기본 자막 폰트, 작업·API 로그. 키는 브라우저에만 보관(선택), ffmpeg·폰트는 `studio.config.json`(git 제외 — `studio.config.example.json` 참고), 프로젝트 목록은 `projects.json`(git 제외).

## 구조
- `server.mjs` : 의존성 없는 Node 서버. 프로젝트 열기·전환, 대본 읽기/쓰기, TTS 생성·서빙, 영상 Range 스트리밍, ElevenLabs·AI 프록시(키는 요청 헤더로만 전달, 디스크에 저장하지 않음)
- `projects.mjs` : 프로젝트 레지스트리·생성·이전(구버전 변환)·파일 탐색·ffprobe
- `export.mjs` : MP4 내보내기 (ASS 자막 생성 + ffmpeg 한 번에 트림·번인·TTS 덕킹 믹스, 진행률 추적, 하드웨어 인코더 감지)
- `fonts.mjs` : Google Fonts 카탈로그·설치(프로젝트 `fonts/`에 TTF 저장). 미리보기와 ffmpeg가 같은 파일 사용
- `thumbs.mjs` : 썸네일 레이어 → ASS → 1280×720 PNG 렌더, 배경·후보 프레임 추출, AI 도구 정의
- `shared/` : 미리보기·편집기·서버 렌더가 공유하는 정의 (`layout.js` 자막·스타일, `cards.js` 카드 모델·변수, `thumbLayers.js` 썸네일 템플릿, `tracks.js` 나레이션 트랙·내보내기 조합)
- `src/` : React UI (Vite). 수정 후 `npm install && npm run build` 로 `dist/` 갱신. 개발 시 `npm run dev` + `node server.mjs`
- `dist/` : 빌드된 UI (서버가 그대로 서빙)

## 흐름
1. API 키 입력 → **보이스 불러오기**(계정의 보이스·TTS 모델 목록) → 보이스 / 모델(기본 Eleven v4) / 설정 선택
   - 모델이 지원하는 설정만 표시. v4는 안정성·유사도만 지원하고 Style·Speed·SSML은 미지원 → 톤은 오디오 태그로 지시
   - **기본 톤**(v3/v4): `[narrator][calm]`처럼 태그를 정해두면 모든 대사 생성 시 발음 텍스트 앞에 자동으로 붙음. 프리셋 칩으로 토글, 직접 입력 가능. 줄 발음이 태그로 시작하면 그 줄은 자체 태그 우선(옵션). 톤을 바꾸면 기존 음성은 '변경' 표시
2. 대사 편집 — **자막**(영상에 표시)과 **발음**(TTS로 전송) 분리
   - 발음 칸이 비어 있으면 자막에 **발음 사전**(자막 표기 → 읽는 법)을 적용한 텍스트를 전송
   - 특정 줄만 따로 고치려면 발음 칸의 `편집`(자동 텍스트 복사) 후 수정, `자동`으로 되돌림
   - 발음 텍스트·보이스·모델이 바뀐 줄은 '변경'으로 표시되어 재생성 대상
3. 저장: 상단 `● 저장` 버튼(또는 Ctrl+S)이 대사·자막 스타일·카드·업로드 문구를 한 번에 저장. 저장 안 된 변경이 있으면 주황색으로 표시
   **멀티 트랙 타임라인** (영상 아래)
   - 눈금 / 영상(사용 구간·챕터 이름·엔딩) / 카드(인트로·챕터·엔딩) / 나레이션(자막·음성) / 썸네일(초안 장면 위치) 트랙
   - 나레이션 블록 드래그 = 대사 시작 시각 이동(0.1초, Alt=0.01초, 재생 위치 근처에서 자석, Esc 취소), 클릭 = 선택·목록 스크롤
   - 카드 블록 드래그 = 인트로 시작 / 챕터 카드 위치(챕터별, 카드 탭 챕터 목록의 ↺로 공통 규칙 복귀), 클릭 = 카드 탭에서 편집
   - 썸네일 표시 클릭 = 그 초안 편집, 빈 곳 클릭·드래그 = 재생 위치 이동
   - `−`/`+` 또는 Ctrl+휠로 확대(최대 40배), 재생 중에는 재생 위치를 따라 스크롤
4. 줄별 `생성` 또는 하단 `이 영상 미생성·변경분 생성` / `이 영상 전체 재생성` → 작업 폴더 `tts/{id}.mp3` (+ 생성 당시 발음·자막·모델 정보 `{id}.json`)
   **나레이션 트랙** (대사 탭 위 `트랙` 줄)
   - 트랙마다 대사·시작 시각·보이스(목소리·모델·언어 코드·톤)·발음 사전이 따로 있음. 트랙 목록은 프로젝트 공통(모든 영상에 같은 트랙)
   - `＋ 트랙`: **AI 번역**(원본 트랙 대사를 시작 시각 그대로 복제 + 자막을 설정의 AI 에이전트로 번역, 발음 사전은 빈 상태) / **그대로 복제**(같은 언어의 다른 버전) / **빈 트랙**
   - 트랙 칩을 누르면 목록·타임라인·미리보기·보이스·발음 사전·실제 렌더 확인·AI 어시스턴트가 그 트랙 기준으로 바뀜. ⚙(또는 더블클릭)로 이름 변경·삭제 (기본 트랙은 삭제 불가)
   - 대사 id: 기본 트랙 `A01`, 추가 트랙 `A_en01` (mp3도 `tts/A_en01.mp3`)
   - `script.json`: 트랙 목록 `tracks`, 대사의 `track` 필드(없으면 기본 트랙), 기본 트랙 보이스·사전은 예전처럼 최상위 `voice`·`pronunciation`
5. `▶ 영상` / `▶ 편집본 재생`으로 잘린 편집본 타임라인 위에서 자막+음성 확인 (나레이션 중 게임음 자동 감쇄)
   - 미리보기 자막·카드는 실제 영상 프레임 영역에 맞춰 비율로 그려짐(창/패널 크기와 무관하게 최종본과 같은 위치·크기·줄바꿈)
   - `🎞 실제 렌더 확인`: 현재 위치를 내보내기와 동일한 ffmpeg+libass로 한 프레임 렌더해 영상 위에 겹쳐 비교
6. 레이아웃: 열 사이 분할선을 드래그해 가운데 패널·어시스턴트 너비 조절, 영상 아래/썸네일 캔버스 아래 분할선으로 높이 조절 (더블클릭 = 초기화, 브라우저에 기억). 패널(보이스·발음 사전)은 접기 가능. 작업·API 로그는 **설정 → 작업 · API 로그**(오류/완료 필터, 복사). 완료·오류는 상단에 잠깐 알림으로 뜨고(클릭 시 로그로 이동), 확인 안 한 오류 수는 설정 버튼 배지로 표시
7. **AI 어시스턴트** (오른쪽 상시 패널, 접기 가능)
   - 대사·자막 스타일·카드·썸네일 어느 작업 중이든 같은 대화로 도움. 지금 보고 있는 작업을 인식해 컨텍스트(대본·타이밍·스타일·선택 썸네일 레이어)와 이미지(영상 화면 또는 썸네일 렌더)를 보냄
   - `propose_edits` 도구로 대사/사전/자막 스타일/카드/썸네일 레이어·배경 변경을 **제안**만 함 → 항목별 `적용`/`무시`
   - 제공자(Claude/GPT)와 모델은 **설정 → AI 에이전트**에서 한 번만 선택 (어시스턴트·썸네일 AI 초안 공통)
8. **자막 스타일** 탭
   - 자막 폰트 / 제목 폰트(카드에서 '스타일: 제목 폰트'로 둔 레이어·썸네일 헤드라인)를 Google Fonts에서 검색·선택하면 자동 설치(한글 지원 필터). PC 설치 폰트 직접 지정 가능
   - 본문·강조·외곽선 색(프리셋: 썸네일 톤 등), 자막 크기·외곽선·그림자·아래 여백·줄바꿈 기준, 강조 키워드
   - 미리보기·실제 렌더·MP4·썸네일 모두 같은 스타일 사용 (Ctrl+S로 프로젝트에 저장)
9. **카드** 탭 — 영상에 번인되는 인트로·챕터·엔딩 카드 (썸네일과 별개, `script.json`의 `meta.{A|B}.cards`에 저장)
   - 인트로/챕터/엔딩 선택 → 영상이 그 카드 위치로 이동, 영상 위에서 레이어 클릭·드래그(이동)·핸들(크기), 방향키·Delete·Ctrl+Z/Y
   - 아래 인스펙터: 레이어 추가(텍스트/박스/그라데이션)·순서·숨김, 폰트·크기·자간·불투명도·색·외곽선·그림자·기준점, **등장 애니메이션**(지연·시작 위치 오프셋·이동 시간·페이드)
   - 색은 `본문/강조/어두운`(자막 스타일 연동) 또는 직접 지정, 폰트는 `스타일: 제목/자막 폰트`(연동) 또는 설치 폰트
   - 텍스트 변수: `{date}` `{title}`, 챕터 카드 `{num}` `{kr}` `{en}` (챕터 목록에서 편집) — 챕터 카드는 한 디자인을 모든 챕터에 적용
   - 타이밍: 인트로 시작·길이, 챕터 '구간 시작 + n초'·길이, 엔딩 길이(영상 끝에 붙는 시간), 페이드 인/아웃, 카드 끄기, `기본값` 복원
   - `썸네일에서 가져오기`: 썸네일 초안의 레이어(문구·배치·색·폰트)를 2배 좌표로 옮겨 카드 레이어 교체 (배경 장면 제외, Ctrl+Z 가능)
   - `▶ 카드 재생`으로 애니메이션 확인, `🎞 실제 렌더 확인`으로 ffmpeg 결과 비교
10. **썸네일** 모드 (가운데 패널 `썸네일` 탭 → 왼쪽 작업 화면이 썸네일 편집기로 전환)
   - 가운데: `✦ AI 초안 생성`(최대 10개, 후보 장면 16~24장 → AI가 장면·템플릿·문구·확대 선택 → PNG. 좋은 장면이 부족하면 더 적게), `영상 위치로 새 초안`, 초안 목록(패널 너비에 맞춰 자동 열 배치)
   - 왼쪽 캔버스(1280×720): 레이어 클릭 선택, 드래그 이동(Shift=10px 스냅), 모서리 핸들로 크기, 방향키 미세 이동, Delete 삭제, Ctrl+Z/Y
   - 아래 인스펙터: 레이어 목록(추가/순서/숨김) · 텍스트(폰트·크기·자간·색·외곽선·그림자·기준점) · 박스/그라데이션 · 배경 장면(시각 0.01초 입력·±1프레임/0.1초/1초 이동·주변 장면 필름스트립(1프레임~10초 간격, 클릭·휠 선택)·`,` `.` 키 1프레임(Shift 0.1초)·확대·중심·대비/채도/밝기) · 템플릿 적용
   - 변경은 자동 저장 + 서버 렌더(ffmpeg+libass, 자막과 같은 폰트 파일). `실제 렌더 비교`로 최종 PNG를 겹쳐 확인
   - `PNG 저장` → 출력 폴더 `썸네일/`
11. **업로드** 탭 — 유튜브 업로드용 제목·설명·태그 (`meta.{A|B}.youtube`에 저장)
   - `사실 메모`(촬영일·강조할 내용·행사 해시태그 등)를 적고 `✦ 제목·설명 추천` → 대본·챕터·메모·선택한 썸네일을 근거로 제목 후보 4~6개, 설명, 태그, 해시태그 제안 (근거 없는 내용은 쓰지 않도록 지시)
   - 제목 후보별 `사용`/`복사`, 설명 직접 편집(`설명 되돌리기`로 AI 적용 전으로), 글자 수 표시(제목 100 · 설명 5000 · 태그 500)
   - 챕터 타임스탬프(편집본 챕터 시작 시각, 0:00부터)와 해시태그를 설명 끝에 자동으로 붙임 → `최종 설명 복사` 한 번으로 유튜브 스튜디오에 붙여넣기. 유튜브 챕터 조건(3개 이상·10초 이상) 미충족 시 경고
   - 태그는 쉼표 구분으로 복사 → 스튜디오 '태그' 칸에 그대로
12. **⬇ MP4 내보내기** 창
   - **내보내기 조합**: 음성 트랙 × 자막 트랙(각각 `없음` 가능) × 파일명 접미사. 선택한 영상 × 선택한 조합마다 파일 하나 (조합은 `script.json`의 `exports`에 저장, 없으면 트랙마다 하나)
   - 조합의 **오디오만**: 영상 없이 편집본과 같은 길이의 최종 오디오(게임 소리 + 그 트랙 나레이션)를 `.m4a`로 → 유튜브 스튜디오 → 언어 → 오디오 추가(다국어 오디오 트랙)용. 화면 카드 글자는 바뀌지 않으므로 글자가 적은 카드에 적합
   - 예: `기본`(한국어 음성+자막) / `영어`(영어 음성+자막, `_영어`) / `영어 오디오`(오디오만, `_영어_음성`)
   - 영상별·음성 트랙별 나레이션 생성/변경/겹침 현황 점검 → 해상도(1440/1080/720p)·품질·인코더(NVENC/QSV/AMF/x264 자동 감지)·게임 사운드·엔딩 전 게임 소리 페이드아웃(기본 3초, 미리보기 재생에도 적용)·SRT 옵션 선택
   - 진행률·속도·남은 시간 표시, 취소 가능, 창을 닫아도 백그라운드 진행(상단 버튼에 진행률)
   - 완료 후 미리보기 / 폴더에서 보기. 출력: `…_편집본{접미사}.mp4` (+ 자막 트랙의 `.srt`) / 오디오만 `…_편집본{접미사}.m4a`
   - ffmpeg 필요: `winget install Gyan.FFmpeg` (libass 포함 빌드)
