# 컷 스튜디오

영상에 나레이션(ElevenLabs TTS)·자막·인트로/챕터/엔딩 카드·썸네일·유튜브 업로드 문구를 붙여 MP4로 내보내는 로컬 웹앱.
여러 영상을 **프로젝트**로 묶어 편집합니다.

## 실행
- `start.bat` 더블클릭 (Node.js 18+ 필요) → 브라우저가 http://localhost:5178 으로 열림
- 또는 `node server.mjs`
- ffmpeg 필요: `winget install Gyan.FFmpeg` (libass 포함 빌드)

## 프로젝트
- 앱을 열면 마지막 프로젝트를 표시하는 **최근 프로젝트** 화면부터 시작. 작업을 이어갈 프로젝트를 선택하거나 **새 프로젝트**, **폴더에서 열기**를 사용
- 프로젝트마다 폴더 하나에 편집 데이터(`script.json`)와 생성 파일을 저장. 새 프로젝트의 기본 위치는 `내 비디오\컷 스튜디오\<이름>`이며, 만들 때 변경 가능
- 이름과 저장 위치를 정해 프로젝트를 만든 뒤 첫 영상을 가져옴. 세부 설정은 상단 **프로젝트 → 프로젝트 설정**에서 변경
  - **브랜드 문구** `{brand}` · **대표 키워드** `{tagline}` · **부제 형식** `{subtitle}` (`{title}` = 영상 제목): 인트로·엔딩 카드와 썸네일 템플릿의 기본 문구
  - **프로젝트 설명**: AI 어시스턴트·썸네일 초안·업로드 문구 추천이 사실·톤의 근거로 사용
  - **출력 폴더**: MP4·SRT·썸네일 PNG 저장 위치 (기본 `프로젝트\output`)
- 상단 **프로젝트** 메뉴에서 새 프로젝트를 만들거나 기존 프로젝트를 열고, **프로젝트 닫기**로 시작 화면에 돌아감. 저장하지 않은 변경이 있으면 저장 후 계속, 저장하지 않음, 취소 중 선택
- **영상 추가** (`＋ 영상` 탭): 첫 촬영본을 **소스 영상** 또는 **PC에서 찾기**로 선택(복사하지 않고 원래 위치 사용) → 제목·날짜·엔딩 문구, **편집 순서**(구간 목록), 구간별 **챕터 제목**(적은 구간만 챕터 카드 표시), 엔딩 카드 길이
- **여러 촬영본 이어 붙이기**: 편집 영상 하나 = 위에서부터 이어 붙는 구간 목록이고, 구간마다 다른 촬영본을 쓸 수 있음
  - `＋ 촬영본 추가`: 그 촬영본 전체 길이 구간을 끝에 추가. `＋ 현재 위치부터 구간`: 플레이어에 띄운 촬영본에서 선택한 구간 다음에 10초 구간 추가
  - 구간을 고르면 그 촬영본이 플레이어에 뜨고 `⇤`/`⇥`로 현재 위치를 시작/끝으로. `↑`/`↓`로 순서 변경(챕터도 함께 이동). 플레이어 아래 막대에 이 촬영본에서 쓰는 구간 표시(클릭 = 이동)
  - 소스 패널의 영상 소스에서 `새 편집 영상으로` / `‘영상 제목’에 이어 붙이기`로 바로 가져올 수 있음
  - 해상도·비율이 다른 촬영본은 16:9 프레임에 레터박스로, 소리가 없는 촬영본은 무음으로 채움(미리보기·실제 렌더·썸네일·MP4 공통). 미리보기는 촬영본마다 영상을 미리 불러 두고 구간 경계에서 바꿔 재생
  - `script.json`의 구간은 `[원본 시작, 원본 끝, 원본 파일]`이며, 파일이 영상의 기본 원본(`src`, 첫 구간의 촬영본)과 같으면 생략(이전 `[시작, 끝]` 형식 그대로 호환)
- 영상 탭의 ⚙(또는 더블클릭)으로 같은 설정을 다시 열기·영상 빼기
- **소스** 패널(작업 화면 왼쪽 끝, `⟨`로 접기·분할선으로 너비 조절)에서 영상 제작에 참고할 자료를 모아 AI 컨텍스트로 사용 — 아래 [소스](#소스-ai-컨텍스트) 참고
- 어시스턴트 대화는 편집 화면을 열어 둔 동안 영상과 나레이션 트랙별로 유지
- 이전 버전(작업 폴더 하나만 쓰던 방식)의 `studio.config.json`이 있으면 첫 실행 때 그 폴더를 프로젝트로 자동 등록(원본 `script.preupgrade.json` 백업)

## 소스 (AI 컨텍스트)
NotebookLM처럼 자료를 한꺼번에 올려 두고, 체크한 소스를 AI가 초안을 만들 때 근거로 씁니다. 결과물은 지금처럼 항목별 `적용`/`무시`로 사람이 결정합니다.
- **추가**: 파일을 창 어디에나 끌어다 놓기 / `Ctrl+V`(스크린숏 등) / `파일 선택`(여러 개) / `텍스트 입력` / `PC 영상 연결`
  - 텍스트: `.txt .md .markdown .csv .tsv .json .srt .vtt` (UTF-8, 깨지면 CP949로 다시 읽음), 소스당 50,000자
  - 이미지: 브라우저에서 긴 변 1280px JPEG로 줄여 저장
  - 영상: 끌어다 놓으면 프로젝트 폴더 `sources/`로 **복사**, `PC 영상 연결`은 복사하지 않고 원래 위치 사용(큰 촬영본용). 추가 시 ffprobe로 길이·해상도를 읽고 대표 장면 6장을 추출
  - 여러 파일은 텍스트·이미지 먼저, 영상은 뒤에 차례로 처리하며 진행률(복사 %·프레임 추출 중)을 표시
- **목록**: 체크 = AI 컨텍스트에 포함, `모두 선택`, 사용량 막대(텍스트 50,000자 · 이미지와 영상 프레임 합계 20장). 한도를 넘는 소스는 꺼진 상태로 추가되고 이유를 표시
- **소스 열기**(항목 클릭): 제목·본문·메모를 고쳐 `변경 저장`, 이미지 원본 보기, 영상 재생
  - 영상의 **AI에 보낼 장면**: 플레이어 위치로 `＋ 현재 장면`, 장면별 `✕`, `균등 재추출`(2~12장). 장면 클릭 = 그 위치로 이동
  - **AI에게 알려줄 메모**: 이 소스의 용도(예: "톤 참고용, 사실 근거로 쓰지 말 것")를 적으면 AI가 사용 지침으로 따름. 소스 본문 안의 지시문은 따르지 않도록 안내
  - 영상 소스는 `편집 영상으로 추가`로 바로 편집 영상 탭에 가져옴(구간·챕터 설정 창이 열림). 편집 영상으로 쓰는 복사본은 소스를 지워도 파일을 남김
- **영상 분석(정보 추출)**: 영상 소스 상세의 `장면 전환`·`받아쓰기`, 또는 목록 위 `영상 분석` 줄에서 여러 영상을 한 번에. 프로젝트마다 하나씩 차례로 실행되고 목록·상세에 진행률 표시, 끝나면 알림
  - **장면 전환** (로컬 ffmpeg, 무료): 화면이 크게 바뀌는 시각을 찾음. 민감도 낮음/보통/높음, 1초보다 짧은 장면은 합침(게임 화면의 섬광·폭발 오검출 방지)
    - 장면 클릭 = 그 위치로 이동, `＋ 현재 위치에서 나누기`, 장면별 `합치기`로 경계를 직접 고침. `장면마다 대표 장면`으로 AI에 보낼 프레임을 장면별 가운데 장면(최대 12장)으로
  - **받아쓰기** (ElevenLabs Speech-to-Text, 설정의 ElevenLabs 키 사용, 사용량 발생): 오디오만 모노 16kHz로 뽑아 보내고 단어 타임스탬프를 문장 단위(쉼·문장부호·화자)로 묶음. 언어(자동/한국어/영어/일본어/중국어)·모델(`scribe_v2`/`scribe_v1`)·화자 구분 선택
    - 문장 시각 클릭 = 이동, 문장 직접 고치기·빼기, **찾아 바꾸기**(게임 용어 오인식 교정, 예: 로콘 → 록온) 후 `변경 저장`. 소리가 없는 영상은 받아쓰기 대상에서 빠짐
  - 결과는 `AI에 포함` 체크로 소스마다 켜고 끔. AI에는 `장면 n개(시작–끝)`와 `[시작–끝] (화자:) 문장` 형식의 텍스트로 들어가고 컨텍스트 텍스트 한도에 포함. 결과를 붙였을 때 한도를 넘으면 그 결과의 AI 첨부만 꺼짐
  - 저장: 장면 경계·분석 상태는 `sources.json`, 받아쓰기 문장은 `sources/<id>/transcript.json`
- **AI 컨텍스트** 탭: 실제 요청에 붙는 내용을 그대로 표시 — 프로젝트 설명(시스템 프롬프트), 소스 번호·머리글·본문, 첨부 이미지와 장면 캡션, 함께 전달되는 규칙. 어시스턴트의 `소스 n/m개 첨부` 버튼으로도 열 수 있음
- 사용처: 어시스턴트(메시지마다), 썸네일 AI 초안, 업로드 문구 추천, 트랙 번역(텍스트만)
- 저장: 목록은 프로젝트 폴더의 `sources.json`, 파일은 `sources/<id>/`(이미지, 복사한 영상, 대표 장면 `f_<ms>.jpg`). 이전 버전의 `references.json`은 처음 열 때 자동으로 옮기고 원본은 그대로 둠

## 설정
상단 `⚙ 설정`: API 키(ElevenLabs / Claude / OpenAI, 연결 테스트), AI 제공자·모델, ffmpeg 경로, 기본 자막 폰트, 작업·API 로그. 키는 브라우저에만 보관(선택), ffmpeg·폰트는 `studio.config.json`(git 제외 — `studio.config.example.json` 참고), 프로젝트 목록은 `projects.json`(git 제외).

## 구조
- `server.mjs` : 의존성 없는 Node 서버. 프로젝트 열기·전환, 대본 읽기/쓰기, TTS 생성·서빙, 영상 Range 스트리밍, ElevenLabs·AI 프록시(키는 요청 헤더로만 전달, 디스크에 저장하지 않음)
- `projects.mjs` : 프로젝트 레지스트리·생성·이전(구버전 변환)·파일 탐색·ffprobe
- `sources.mjs` : 프로젝트 소스 저장(텍스트·이미지·영상, 대표 장면 추출, 한도), 분석 작업 큐, 컨텍스트 미리보기와 AI 요청 첨부. `shared/sources.js`는 한도·머리글·장면/받아쓰기 형식을 UI와 공유
- `analysis.mjs` : 영상 소스 분석 — 장면 전환 감지(ffmpeg scene score), 받아쓰기(ElevenLabs Speech-to-Text, 단어 → 문장 묶기)
- `export.mjs` : MP4 내보내기 (ASS 자막 생성 + ffmpeg 한 번에 트림·번인·TTS 덕킹 믹스, 진행률 추적, 하드웨어 인코더 감지)
- `fonts.mjs` : Google Fonts 카탈로그·설치(프로젝트 `fonts/`에 TTF 저장). 미리보기와 ffmpeg가 같은 파일 사용
- `thumbs.mjs` : 썸네일 레이어 → ASS → 1280×720 PNG 렌더, 배경·후보 프레임 추출, AI 도구 정의
- `shared/` : 자막·카드·썸네일과 편집 데이터 정의. `tracks.js`는 나레이션 트랙과 내보내기 조합, `voices.js`는 보이스 설정과 대사별 적용 우선순위, `clips.js`는 구간별 촬영본과 레터박스 규칙을 관리
- `src/` : React UI (Vite). 수정 후 `npm install && npm run build` 로 `dist/` 갱신. 개발 시 `npm run dev` + `node server.mjs`
- `dist/` : 빌드된 UI (서버가 그대로 서빙)

## 흐름
1. 설정에서 ElevenLabs API 키 입력 → **보이스 불러오기**로 계정의 보이스와 모델 목록을 가져옴. **보이스** 탭에서 이름, 목소리, 모델, 언어 코드, 생성 옵션을 지정해 여러 보이스를 관리
   - **트랙 기본 보이스**에서 현재 나레이션 트랙의 기본값을 선택. 대사별 **보이스** 선택은 `기본`으로 두고, 다른 목소리가 필요한 줄에서만 변경
   - 모델이 지원하는 설정만 표시. v4는 안정성·유사도만 지원하고 Style·Speed·SSML은 미지원 → 톤은 오디오 태그로 지시
   - **기본 톤**(v3/v4)은 해당 보이스로 생성할 때 발음 텍스트 앞에 붙음. 프리셋 칩으로 토글하거나 `[narrator][calm]`처럼 직접 입력. 대사 자체의 태그를 우선하도록 설정할 수 있음
2. 대사 편집 — **자막**(영상에 표시)과 **발음**(TTS로 전송) 분리
   - 발음 칸이 비어 있으면 **보이스 → 발음 사전**에서 관리하는 현재 트랙의 규칙을 자막에 적용
   - 특정 줄만 따로 고치려면 발음 칸의 `편집`(자동 텍스트 복사) 후 수정, `자동`으로 되돌림
   - 발음 텍스트·보이스·모델이 바뀐 줄은 '변경'으로 표시되어 재생성 대상
3. 저장: 상단 `● 저장` 버튼(또는 Ctrl+S)이 대사·자막 스타일·카드·업로드 문구를 한 번에 저장. 저장 안 된 변경이 있으면 주황색으로 표시
   **멀티 트랙 타임라인** (작업창 하단 패널)
   - 하단 패널에서 재생, 처음으로 이동, 원본 볼륨 조절. 제목 옆 버튼으로 트랙 영역을 접거나 펼칠 수 있음
   - 패널 위 분할선을 위아래로 드래그해 트랙 높이 조절. 높이는 브라우저에 저장되고, 분할선을 더블클릭하면 기본 높이로 복귀
   - 눈금 / 영상(사용 구간·챕터 이름·엔딩) / 카드(인트로·챕터·엔딩) / 나레이션(자막·음성) / 썸네일(초안 장면 위치) 트랙
   - 나레이션 블록 드래그 = 대사 시작 시각 이동(0.1초, Alt=0.01초, 재생 위치 근처에서 자석, Esc 취소), 클릭 = 선택·목록 스크롤
   - 카드 블록 드래그 = 인트로 시작 / 챕터 카드 위치(챕터별, 카드 탭 챕터 목록의 ↺로 공통 규칙 복귀), 클릭 = 카드 탭에서 편집
   - 썸네일 표시 클릭 = 그 초안 편집, 빈 곳 클릭·드래그 = 재생 위치 이동
   - 타임라인 위에서 Ctrl+휠로 커서가 가리키는 지점을 기준으로 확대·축소(최대 80배). 상단의 `−`/`+` 버튼으로도 조절
   - Shift+휠 또는 가로 스크롤바로 표시 범위 이동. 상단에서 현재 범위를 확인하고 `전체 보기`로 복귀. 재생 중에는 재생 위치를 따라 스크롤
4. 줄별 `생성` 또는 하단 `미생성·변경분 생성` / `전체 재생성` → 현재 영상과 트랙의 음성을 작업 폴더 `tts/{id}.mp3`에 저장 (+ 생성 당시 발음·자막·모델 정보 `{id}.json`)
   **나레이션 트랙** (대사 탭 위 `트랙` 줄)
   - 모든 영상에서 같은 트랙 목록을 사용. 대사·시작 시각·기본 보이스·발음 사전은 트랙별로 관리하고 보이스 목록은 프로젝트에서 공유
   - `＋ 트랙 추가`: **AI 번역**(원본 트랙 대사를 시작 시각 그대로 복제 + 자막을 설정의 AI 에이전트로 번역, 발음 사전은 빈 상태) / **그대로 복제**(같은 언어의 다른 버전) / **빈 트랙**
   - 트랙을 선택하면 목록·타임라인·미리보기·보이스·발음 사전·실제 렌더 확인·AI 어시스턴트가 그 트랙 기준으로 바뀜. `⚙ 설정`에서 이름 변경·삭제 (기본 트랙은 삭제 불가). 빈 트랙에서는 `＋ 첫 대사 추가`로 재생 위치에 대사를 넣을 수 있음
   - 대사 id: 기본 트랙 `A01`, 추가 트랙 `A_en01` (mp3도 `tts/A_en01.mp3`)
   - `script.json`의 `voiceProfiles`는 프로젝트 보이스 목록, `trackVoices`는 트랙 기본값, 대사의 `voiceProfileId`는 개별 선택을 저장. 기존 프로젝트를 열면 트랙별 보이스 설정을 기본 보이스로 가져오며, 저장 시 새 필드를 기록
5. `▶ 영상` / `▶ 편집본 재생`으로 잘린 편집본 타임라인 위에서 자막+음성 확인 (나레이션 중 원본 오디오 자동 감쇄)
   - 미리보기 자막·카드는 실제 영상 프레임 영역에 맞춰 비율로 그려짐(창/패널 크기와 무관하게 최종본과 같은 위치·크기·줄바꿈)
   - `🎞 실제 렌더 확인`: 현재 위치를 내보내기와 동일한 ffmpeg+libass로 한 프레임 렌더해 영상 위에 겹쳐 비교
6. 기본 레이아웃은 상단에 미리보기와 편집 패널, 하단에 타임라인을 배치. 오른쪽 버튼으로 AI 어시스턴트를 열 수 있음. 열 사이와 미리보기 아래 분할선으로 패널 크기를 조절할 수 있으며, 하단의 `레이아웃 초기화`로 기본 배치 복원. 작업·API 로그는 **설정 → 작업 · API 로그**에서 확인. 상단의 완료·오류 알림을 클릭하면 로그로 이동하며, 확인 안 한 오류 수는 설정 버튼 배지에 표시
7. **AI 어시스턴트** (오른쪽 상시 패널, 접기 가능)
   - 대사·자막 스타일·카드·썸네일 어느 작업 중이든 같은 대화로 도움. 지금 보고 있는 작업을 인식해 컨텍스트(대본·타이밍·스타일·선택 썸네일 레이어)와 이미지(영상 화면 또는 썸네일 렌더)를 보냄
   - `propose_edits` 도구로 대사/사전/자막 스타일/카드/썸네일 레이어·배경 변경을 **제안**만 함 → 항목별 `적용`/`무시`
   - 제공자(Claude/GPT)와 모델은 **설정 → AI 에이전트**에서 한 번만 선택 (어시스턴트·썸네일 AI 초안 공통)
8. **자막 스타일** 탭
   - 자막 폰트 / 제목 폰트(카드에서 '스타일: 제목 폰트'로 둔 레이어·썸네일 헤드라인)를 Google Fonts에서 검색·선택하면 자동 설치(한글 지원 필터). PC 설치 폰트 직접 지정 가능
   - 본문·강조·외곽선 색(프리셋: 썸네일 톤 등), 자막 크기·외곽선·그림자·아래 여백·줄바꿈 기준, 강조 키워드
   - 미리보기·실제 렌더·MP4·썸네일 모두 같은 스타일 사용 (Ctrl+S로 프로젝트에 저장)
9. **카드** 탭 — 영상에 번인되는 인트로·챕터·엔딩 카드 (썸네일과 별개, `script.json`의 `meta.{A|B}.cards`에 저장)
   - 인트로/챕터/엔딩 선택 → 영상이 그 카드 위치로 이동, 영상 위에서 레이어 클릭·드래그(이동)·핸들(크기), 방향키·Delete·Ctrl+Z/Y
   - 아래 인스펙터: 레이어 추가(텍스트/박스/그라데이션)·순서·숨김, 폰트·크기·자간·불투명도·색·외곽선·그림자·기준점, **등장 애니메이션**(지연·시작 위치 오프셋·이동 시간·페이드)
   - 색은 `본문/강조/어두운`(자막 스타일 연동) 또는 직접 지정, 폰트는 `스타일: 제목/자막 폰트`(연동) 또는 설치 폰트
   - 텍스트 변수: `{date}` `{title}`, 챕터 카드 `{num}` `{kr}` `{en}` (챕터 목록에서 편집) — 챕터 카드는 한 디자인을 모든 챕터에 적용
   - 타이밍: 인트로 시작·길이, 챕터 '구간 시작 + n초'·길이, 엔딩 길이(영상 끝에 붙는 시간), 페이드 인/아웃, 카드 끄기, `기본값` 복원
   - `썸네일에서 가져오기`: 썸네일 초안의 레이어(문구·배치·색·폰트)를 2배 좌표로 옮겨 카드 레이어 교체 (배경 장면 제외, Ctrl+Z 가능)
   - `▶ 카드 재생`으로 애니메이션 확인, `🎞 실제 렌더 확인`으로 ffmpeg 결과 비교
10. **썸네일** 모드 (가운데 패널 `썸네일` 탭 → 왼쪽 작업 화면이 썸네일 편집기로 전환)
   - 가운데: `✦ AI 초안 생성`(최대 10개, 후보 장면 16~24장 → AI가 장면·템플릿·문구·확대 선택 → PNG. 좋은 장면이 부족하면 더 적게), `영상 위치로 새 초안`, 초안 목록(패널 너비에 맞춰 자동 열 배치)
   - 왼쪽 캔버스(1280×720): 레이어 클릭 선택, 드래그 이동(Shift=10px 스냅), 모서리 핸들로 크기, 방향키 미세 이동, Delete 삭제, Ctrl+Z/Y
   - 아래 인스펙터: 레이어 목록(추가/순서/숨김) · 텍스트(폰트·크기·자간·색·외곽선·그림자·기준점) · 박스/그라데이션 · 배경 장면(시각 0.01초 입력·±1프레임/0.1초/1초 이동·주변 장면 필름스트립(1프레임~10초 간격, 클릭·휠 선택)·`,` `.` 키 1프레임(Shift 0.1초)·확대·중심·대비/채도/밝기) · 템플릿 적용
   - 변경은 자동 저장 + 서버 렌더(ffmpeg+libass, 자막과 같은 폰트 파일). `실제 렌더 비교`로 최종 PNG를 겹쳐 확인
   - `PNG 저장` → 출력 폴더 `썸네일/`
11. **업로드** 탭 — 유튜브 업로드용 제목·설명·태그 (`meta.{A|B}.youtube`에 저장)
   - `사실 메모`(촬영일·강조할 내용·행사 해시태그 등)를 적고 `✦ 제목·설명 추천` → 대본·챕터·메모·선택한 썸네일을 근거로 제목 후보 4~6개, 설명, 태그, 해시태그 제안 (근거 없는 내용은 쓰지 않도록 지시)
   - 제목 후보별 `사용`/`복사`, 설명 직접 편집(`설명 되돌리기`로 AI 적용 전으로), 글자 수 표시(제목 100 · 설명 5000 · 태그 500)
   - 챕터 타임스탬프(편집본 챕터 시작 시각, 0:00부터)와 해시태그를 설명 끝에 자동으로 붙임 → `최종 설명 복사` 한 번으로 유튜브 스튜디오에 붙여넣기. 유튜브 챕터 조건(3개 이상·10초 이상) 미충족 시 경고
   - 태그는 쉼표 구분으로 복사 → 스튜디오 '태그' 칸에 그대로
12. **⬇ MP4 내보내기** 창
   - **내보내기 조합**: 음성 트랙 × 자막 트랙(각각 `없음` 가능) × 파일명 접미사. 선택한 영상 × 선택한 조합마다 파일 하나 (조합은 `script.json`의 `exports`에 저장, 없으면 트랙마다 하나)
   - 조합의 **오디오만**: 영상 없이 편집본과 같은 길이의 최종 오디오(원본 소리 + 그 트랙 나레이션)를 `.m4a`로 → 유튜브 스튜디오 → 언어 → 오디오 추가(다국어 오디오 트랙)용. 화면 카드 글자는 바뀌지 않으므로 글자가 적은 카드에 적합
   - 예: `기본`(한국어 음성+자막) / `영어`(영어 음성+자막, `_영어`) / `영어 오디오`(오디오만, `_영어_음성`)
   - 영상별·음성 트랙별 나레이션 생성/변경/겹침 현황 점검 → 해상도(1440/1080/720p)·품질·인코더(NVENC/QSV/AMF/x264 자동 감지)·원본 오디오·엔딩 전 원본 소리 페이드아웃(기본 3초, 미리보기 재생에도 적용)·SRT 옵션 선택
   - 진행률·속도·남은 시간 표시, 취소 가능, 창을 닫아도 백그라운드 진행(상단 버튼에 진행률)
   - 완료 후 미리보기 / 폴더에서 보기. 출력: `…_편집본{접미사}.mp4` (+ 자막 트랙의 `.srt`) / 오디오만 `…_편집본{접미사}.m4a`
   - ffmpeg 필요: `winget install Gyan.FFmpeg` (libass 포함 빌드)
